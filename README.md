# alfiecodes

A browser IDE for a young coder: [code-server](https://github.com/coder/code-server)
with Python, pygame-ce, pygbag and Pygame Zero preinstalled. Built by CI to
`ghcr.io/calmstilton/alfiecodes:latest`.

`compose.yml` is the stack that runs it. Put `PASSWORD=...` in a `.env` file beside it.
