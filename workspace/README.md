# Welcome to Alfie Codes!

Every game lives in its own folder. Inside the folder is a file called `game.py`.

## Try your game

1. Click on your `game.py` file so it is open.
2. Press **F5**, or click **Play** at the very bottom of the screen.
3. Wait a moment. A web address appears in the box at the bottom. Open it.
4. Click the page to start. Press **Ctrl+C** in the bottom box when you have finished.

## Share your game

1. Click on your `game.py` file so it is open.
2. Press **F6**, or click **Publish** at the very bottom of the screen.
3. When it says **Published**, your game is on the arcade page.

## If something goes wrong

A red screen means Python found a mistake. It tells you the line number.
Fix that line, then press **F5** again.
