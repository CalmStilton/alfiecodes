# How to use Alfie Codes

Every project lives in its own folder. A game needs a file called `game.py` inside its folder.
A website needs a file called `index.html`.

## Try your project

1. Click on any file in your project so it is open.
2. Press **F5**, or click **Run** at the very bottom of the screen.
3. Wait a moment. A web address appears in the box at the bottom. Click it, or copy it into a new tab.
4. For a game, click the page to start. Press **Ctrl+C** in the bottom box when you have finished.

## Share your project

1. Click on any file in your project so it is open.
2. Press **F6**, or click **Publish** at the very bottom of the screen.
3. When it says **Published**, your project is on your projects page.

## Saving your work

Your work is saved to GitHub every evening by itself. To save it now with your own message,
click **Source Control** on the left (the branch icon), type what you changed, then click **Commit** and **Sync**.

## If something goes wrong

A red screen means Python found a mistake. It tells you the line number.
Fix that line, then press **F5** again.
